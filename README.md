## Collaboration Guidelines


- `main` branch contains stable code
- `dev` branch is used for integration
- New features are developed in separate `feature/*` branches
- BugFixes are done in separate `bugfix/*` branches
- All changes are merged via Pull Requests
- Code review is required before merging
